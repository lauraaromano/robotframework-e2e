## Filtragem por Categorias

## CT-038 — Realizar filtragem de roupas femininas por vestidos com sucesso

**Objetivo:**  
Validar se o sistema realiza corretamente a filtragem de produtos da categoria feminina, utilizando o filtro de vestidos (Dress).

**Pré-condições:**  
Aplicação disponível, usuário previamente cadastrado e login realizado.

**Dados de teste:**

- Categoria: `Women`
- Subcategoria: `Dress`

**Passos:**

1. Acessar a aplicação.
2. Realizar login com um usuário cadastrado.
3. Acessar a página de produtos.
4. Selecionar a categoria Women.
5. Selecionar a subcategoria Dress.
6. Validar os produtos exibidos.

**Resultado esperado:**  
O sistema deve realizar a filtragem com sucesso, exibindo somente os produtos correspondentes à categoria feminina e à subcategoria de vestidos.

**Prioridade:** Média

**Tipo:** E2E | Funcional | Positivo
